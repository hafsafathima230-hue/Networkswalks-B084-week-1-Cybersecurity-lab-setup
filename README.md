# Networkswalks-B084-week-1-Cybersecurity-lab-setup
**Cybersecurity lab setup**

**Project Overview**

This project focuses on setting up a virtual cybersecurity and penetration testing laboratory using Oracle VirtualBox and Kali Linux. The purpose of the lab is to create a controlled environment where cybersecurity tools and techniques can be practiced safely and repeatedly.

The lab provides a foundation for performing network scanning, reconnaissance, vulnerability assessment, packet analysis, and other authorized security testing activities. A private virtual network is configured to support future expansion by adding additional virtual machines that can serve as targets for authorized security testing.

As part of this Week 1 project, I completed the initial lab setup and configuration, followed by six hands-on Wireshark SOC labs provided by NetworkWalks. These exercises helped me understand network traffic analysis, suspicious communication patterns, and common cybersecurity threats.

**Project Objectives**

The main objectives of this project are:

- Install and configure Oracle VirtualBox.
- Install or import Kali Linux as a virtual machine in VirtualBox.
- Create a private virtual network for the cybersecurity laboratory.
- Configure and verify network connectivity for Kali Linux.
- Prepare a controlled environment for authorized cybersecurity and penetration testing activities.
- Develop practical skills in network scanning, reconnaissance, and vulnerability assessment.
- Perform hands-on network traffic analysis using Wireshark.
- Understand common attack patterns and foundational Security Operations Center (SOC) investigation techniques.

**Project module-1(Extra): Virtual Cybersecurity Lab Setup**

### Tools and Technologies

- **Oracle VirtualBox:** Virtualization software used to create and manage virtual machines.
- **Kali Linux:** A Linux distribution containing tools for cybersecurity testing and security analysis.
- **Private Virtual Network:** A network configuration for communication between lab virtual machines.
- **Wireshark:** A network protocol analyzer used to inspect and analyze captured traffic.

### Setup Activities

1. Installed and configured Oracle VirtualBox.
2. Installed or imported Kali Linux into VirtualBox as a virtual machine.
3. Configured the virtual machine's network settings.
4. Created a private virtual network for the lab environment.
5. Checked Kali Linux network connectivity.
6. Prepared the environment for future authorized security testing and practical exercises.

### Outcome

Successfully completed the initial virtual cybersecurity lab setup, establishing a foundation for hands-on security learning and network analysis. The lab environment can be extended by adding additional virtual machines for authorized testing.

## Project module-1(Extra): NetworkWalks Wireshark SOC Labs

After completing the virtual lab setup, I worked on six hands-on SOC labs using Wireshark and the lab exercises provided by NetworkWalks.

### Labs Completed

### 1. Identify the Attacker's IP
- Analyzed captured network traffic to identify the attacker's IP address.
- Practiced inspecting packets and recognizing suspicious communication.

### 2. Follow TCP Stream – Part 1
- Used Wireshark's Follow TCP Stream feature.
- Reconstructed a TCP conversation to understand the data exchanged between systems.

### 3. Follow TCP Stream – Part 2
- Analyzed another packet capture using TCP stream reconstruction.
- Practiced examining network communication to identify relevant information.

### 4. HTTP Plain Text Credentials
- Examined HTTP traffic to understand how credentials may be exposed in unencrypted communication.
- Learned the importance of HTTPS and encryption for protecting sensitive information.

### 5. Catch the Brute Force Attacker
- Investigated repeated login attempts in network traffic.
- Learned to recognize patterns that may indicate a brute-force attack.

### 6. Catch the Call Scammer
- Investigated the provided network capture associated with a call-scam scenario.
- Practiced examining traffic for suspicious communication patterns.
